# Pedro Henrique — Portfolio

> Portfolio pessoal desenvolvido para apresentar minha trajetória acadêmica, experiência prática, projetos e conhecimentos em tecnologia.

🌐 **Acesse o portfolio:** [pedrqca.dev](https://pedrqca.dev)

---

## Sobre o projeto

Este projeto é o meu portfolio pessoal, desenvolvido para centralizar minha trajetória como estudante de Engenharia de Computação e desenvolvedor.

A proposta é apresentar, de forma simples e objetiva:

- Minha trajetória acadêmica
- Experiência prática
- Projetos desenvolvidos
- Conhecimentos técnicos
- Tecnologias com as quais trabalho
- Formas de contato e redes profissionais

O projeto também serve como um espaço para experimentar tecnologias, interfaces e boas práticas de desenvolvimento frontend.
